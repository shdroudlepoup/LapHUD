LapHUD — le HUD télémétrie style F1 pour tes vidéos embarquées (GoPro + RaceBox)
==================================================================================

Utilisation
-----------
1. Lance LapHUD.exe (rien à installer).
2. Glisse dans la fenêtre tes vidéos GoPro et tes CSV RaceBox (ou un dossier entier).
   LapHUD associe chaque vidéo à sa session et la synchronise automatiquement.
3. Vérifie l'aperçu (pastille verte = synchro sûre), choisis le style, puis EXPORTER.

Export du CSV dans l'app RaceBox : format CSV, préréglage « Custom »,
« Full Date/Time in UTC », km/h, Bike Mode décoché.

Compatible : GoPro HERO5 et plus récentes, RaceBox Mini / Mini S / Micro.
Encodage accéléré sur carte NVIDIA, AMD, Intel ou Apple (sinon par le processeur).
Mac / Linux : installe ffmpeg (brew install ffmpeg / sudo apt install ffmpeg).

Option « Retirer les voix » : nécessite Python et  pip install "audio-separator[gpu]"
(carte NVIDIA conseillée). Sans cela, l'option est simplement grisée.

Code source, aide et mises à jour : https://github.com/shdroudlepoup/LapHUD
